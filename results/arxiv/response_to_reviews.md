## Reviewer 4

| Point | Action |
|---|---|
| Inferring "in the weights, not the prompt" | Same narrowing as Reviewer 2. |
| Exported prompts compete with provider system prompts; self-description influence may simply be weak | Positive control: given the author's answers to the 110 test items, receivers reproduce the author at F_cross = 0.960 (Grid A), 0.959 (Grid B), 0.955 (local trio), within 0.02 of the test-retest ceiling, with the author's own weights adding nothing (R_weight about 0). The channel can install a complete profile; the null is about what self-descriptions contain. Placement control: the same self-descriptions and answer key moved from the system prompt to the user message (Grid A, 18 cells) give identical results (answer key F_cross 0.961, T +0.098, 6/6 pairs; self-description T -0.005), so text never needs to sit in the system prompt and compete with provider prompts. Provider-side prompts remain unobservable, stated in Limitations. |
